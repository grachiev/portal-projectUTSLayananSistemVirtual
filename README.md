# Portal Belajar Cendekia

Website layanan pembelajaran daring untuk 500 mahasiswa: materi kuliah, pengumpulan tugas, dan ujian online.

## Struktur
- `index.html` : kerangka halaman
- `style.css`  : tampilan (tema terang dan gelap)
- `script.js`  : logika portal dan data contoh

## Menjalankan
Buka `index.html` di browser, atau pakai ekstensi Live Server di VS Code.
